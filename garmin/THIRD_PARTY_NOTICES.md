## JetBrains Mono

The time display uses glyphs generated from JetBrains Mono Regular. The tall
minute atlas stretches the generated time glyphs vertically. Numeric dates and
widget text use JetBrains Mono NL Thin, the non-ligature variant.
The generated zero glyphs omit the interior dot while retaining their outlines.

## Tabler Icons

The data-slot and dynamic-weather symbols are modified colour-ready copies of
Tabler outline icons, including Heart, Temperature, Temperature Sun, Stairs,
Footsteps, Run, Sun, Cloud, Cloud Rain, Cloud Storm, Snowflake, Mist, and Wind.
The retained SVG sources generate PNG assets with a shared visible icon height.

## Locally installed Garmin simulator assets

The local web designer reads device artwork and screen geometry from the user's
installed Garmin Connect IQ device packages. These Garmin assets remain in the
SDK installation and are not included or redistributed in this repository.
